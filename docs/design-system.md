# デザインシステム・部品設計書 (`docs/design-system.md`)

## フェーズ2 サイト全体のデザイン方針

### 1. 業種の定石を知り、そこから離れる

`ui-ux-pro-max` の `search.py "ramen restaurant japanese craft beer fermentation" --design-system` が返した「この業種の平均的な定石」は以下のとおりである。

- **定石の構成**: 中央揃えヒーロー（背景写真＋黒オーバーレイ＋見出し＋ボタン）→ 3枚均等カードの特徴紹介 → 下部CTAバナー → フッター。
- **定石の配色**: クリーム色または薄い赤白の地 + 臙脂・渋赤 (`#7C2D12` / `#B91C1C`) + 琥珀ゴールド (`#A16207`)。
- **定石の書体**: `Noto Serif JP` + `Noto Sans JP`（または `Inter`）。

改修前のサイトは、まさにこの定石と AI テンプレートの癖（全大文字アイブロー、1語だけ赤イタリックの見出し、青海波と透かし漢字、虹色グラデーション上枠のカード）がそのまま出力された状態だった。本刷新ではこれらをすべて比較対象（アンチパターン）として外す。

### 2. 題材の世界から出した7つの視覚候補

- **みつか坊主だけの仕組み（一文）**: 大阪伊丹空港からモノレールで1駅、蛍池駅前のビル2階にある「白味噌ラーメンと箕面ビール・秋鹿の自然酒・豊能の発酵料理が同じ長テーブルに並ぶ、北摂のマイクロ発酵食堂」。
- **訪問者がいる場面・証明すべきこと**: 空港や阪急電車から降り立った旅行者が階段を上がった先に、観光地向けのフェイクな「忍者・芸者・青海波の和食店」ではなく、**漆喰とコンクリートの明るい空間で、デニムエプロンの店主が5種の小鉢を出し、タップから箕面ビールが注がれ、朱塗りの鉢で白味噌ラーメンが湯気を立てている本物のローカルの食卓**があることを最初の画面で証明する。

題材の世界にある具体的な視覚の体系・物・場所・習慣から7候補を導出した（素材系統：①建築・空間、②醸造・道具、③印刷・帳票、④器・食卓）：

1. **【候補1・建築】蛍池2階・モノレールを見下ろす鉄枠アーチ窓と白漆喰の食堂**（素材系統：建築・左官・黒鉄）
   - *なぜ響くか*: 実店舗写真（`0303_1N0A1489.jpg`, `mitsukabose-food.jpg`）で最も印象的な、2階の大きなアーチ窓と白漆喰壁・古材テーブルの空間そのものだから。
   - *どう見えるか*: 明るい白漆喰の地 (`#F6F3EC`) とモルタルの淡灰 (`#EAE4D8`)、窓枠の黒鉄色 (`#1C1917`)、力強い明朝体と端正なゴシック体、黒鉄の細い構造線（1px border）で区切られた建築的なグリッド。
2. **【候補2・印刷/帳票】醸造所の仕込み帳と酒販店のスペック荷札（秋鹿・オリゼーの瓶ラベル）**（素材系統：和紙・活版・罫線帳票）
   - *なぜ響くか*: ラーメンだけでなく「いつの時間帯に・どの味噌/酵母で・どの食事制限に対応し・いくらか」という情報を正確に伝える品書きと相性が抜群だから。
   - *どう見えるか*: 生成り和紙の地に墨色の罫線表、右端に朱印色のタグ、価格は等幅数字 (`tabular-nums`) で縦にピタリと揃い、カードではなく「仕込み表・お品書き帳」として読める。
3. **【候補3・道具】タップルームの黒板メニューと真鍮のドラフトハンドル**（素材系統：黒板・チョーク・真鍮・琥珀）
   - *なぜ響くか*: 箕面ビールやオリゼーのクラフトビールを樽生で注ぐ (`0138_1N0A1489.jpg`) 夜のバルとしての顔を持つから。
   - *どう見えるか*: 深いスレート黒 (`#181614`) の帯に白チョーク色の文字とビール琥珀色 (`#D4882A`) の強調、時間帯（Lunch / Sunset / Dinner / Midnight）を切り替えるタップハンドルのような明確な切替器。
4. **【候補4・器】朱漆のラーメン鉢と白木の五種小鉢トレー**（素材系統：漆器・白木・陶器）
   - *なぜ響くか*: 店主が白木の長盆に5つの小鉢を並べて差し出す写真 (`0054_1N0A0937.jpg`) と、家族が囲む朱塗りの丼が店の象徴だから。
   - *どう見えるか*: 白木の温かみある面の上に、ここぞという主役ボタンとバッジだけに使う「朱漆 (`#A83223`)」の塊。
5. **【候補5・壁画】店内の円形漆喰レリーフ（襟飾りをつけた坊主が麺をすする線画と真鍮の蝶）**（素材系統：現代イラスト・真鍮・左官）
   - *なぜ響くか*: 屋号「みつか坊主」のユーモアと現代性を象徴する店内アート (`0031_1N0A0880.jpg`) だから（※屋号の文字どおりの解釈枠1つ）。
   - *どう見えるか*: 漆喰の白地に繊細な墨の単線画と橙色の波紋線。
6. **【候補6・交通】大阪モノレール・阪急宝塚線の駅名標と路線案内サイン**（素材系統：公共サイン・インダストリアル）
   - *なぜ響くか*: 「伊丹空港から1駅・蛍池駅東口から徒歩1分」という立地の圧倒的な利便性を旅行者に直感させるから。
   - *どう見えるか*: 駅ナンバリングや所要時間（「ITM Airport → 3 min → Hotarugaike → 1 min walk」）を明快なダイヤグラム線で示す案内板。
7. **【候補7・里山】能勢の棚田と豊能の味噌樽（木桶と藁）**（素材系統：農・自然素材）
   - *なぜ響くか*: 秋鹿の無農薬山田錦や豊能町の「かあちゃん味噌」の産地である北摂の里山を表すから。
   - *どう見えるか*: 藁色と葉緑色、素朴な明朝体。

### 3. 一つに決めた視覚世界と計画

**採用する方向性**: **【候補1 × 候補2 の融合】「蛍池二階・醸造食堂の建築グリッドと仕込み帳（2F Hotarugaike Fermentation Hall & Brew Ledger）」**
（部分的に候補3の「黒板ステータス帯」と候補6の「空港・駅1分ルート図」を機能部品として組み込む）

#### なぜこの方向性か
訪問者は日中・移動中のスマホでも、夜の室内でもこのサイトを見る。真っ黒な居酒屋サイトにすると昼の爽やかな食堂感と可読性が死に、逆にフワフワしたクリーム色のAIカードサイトにすると「本物の醸造食堂」の骨格が消える。
実店舗の**「白漆喰の壁 (`#F6F2EA`) × 窓枠と黒板の黒鉄墨 (`#1A1714`) × 古材テーブルの煤竹 (`#3D3024`) × 朱漆の丼 (`#A62E20`) × 箕面ビールの琥珀 (`#C87A24`)」**をそのままページの構造材にする。影やグラデーションで浮かせる SaaS カードをやめ、**1px の黒鉄／煤竹の構造罫線（Ledger Grid）と余白の対比**でページを組む。

#### 書体（3書体・役割分担を明確化）
- **見出し（Display / Serif）**: **`Shippori Mincho`**（しっぽり明朝、Weight 500, 700）
  - 東京築地活版製造所の五号明朝にならった、端正で懐が深く、欧文・和文ともに品格のある明朝体。`Noto Serif JP` の定石から離れ、発酵・酒造のラベルらしい骨格を出す。
- **本文（Body / Sans）**: **`Plus Jakarta Sans`**（欧文、Weight 400, 500, 600）＋ **`Zen Kaku Gothic New`**（和文、Weight 400, 500, 700）
  - `Inter` の無機質なデフォルト感を避け、幾何学的すぎず人間味と高い可読性を持つ `Plus Jakarta Sans` と `Zen Kaku Gothic New` を組み合わせる。
- **数値・価格・時刻（Tabular / Mono）**: **`JetBrains Mono`**（Weight 400, 500）
  - 「技術っぽさの衣装」としてラベルに使うのではなく、**価格 (`¥1,080`)、時間帯 (`11:30–14:30`)、徒歩分数 (`1 min`) の桁揃え (`tabular-nums`) に限定**して使用する。

#### 原則（このサイトを他と違うものにする4つの規律）
1. **飾りではなく事実の構造を見せる**: 青海波や浮遊漢字や虹色バーはすべて捨てる。その代わりに「どの時間帯に何が頼めるか」「どの味噌・どの蔵の酒粕を使っているか」「どの食制限に対応しているか」を仕込み帳のような罫線とタグで明快に見せる。
2. **最初の画面で目的を達する**: トップページを開いた瞬間に、時間帯別の代表メニューと価格、営業時間、駅からのルートがその場で操作・確認できる。
3. **実写真の空気を殺さない**: 店内やラーメンの写真の上に濃い茶色のグラデーションをベタ塗りして文字を載せない。写真は写真の枠で鮮やかに見せ、文字は白漆喰か黒鉄の面の上でくっきり読ませる。
4. **インバウンド客の「現場の困りごと」を解決する**: 「2Fの入口階段が分かりにくい」「店員やタクシーに日本語で伝えたい」「豚肉や動物性食材が入っているか知りたい」をUIの機能として組み込む。

### 4. 計画の見直し（AIの5つの集まる場所との照合）

1. *クリーム色＋セリフ＋テラコッタの安易な組み合わせになっていないか？*
   → 単なる中立クリームではなく、店舗の「白漆喰 (`#F6F2EA`) × 黒鉄窓枠 (`#1A1714`)」の1px構造グリッド（Ledger Grid）を骨格にし、アクセントはテラコッタではなく朱塗り丼の「朱漆 (`#A32C1E`)」に絞った。
2. *SaaS風カード一式になっていないか？*
   → `rounded-md shadow-cinematic` の浮遊カードを廃止し、1px の黒鉄／煤竹罫線で区切られた「お品書き帳（Menu Ledger）」と「編集記事（Editorial Story）」のレイアウトに変更した。
3. *見出し上の全大文字アイブロー・中黒つなぎ・1語イタリック・連番が残っていないか？*
   → 全ページからアイブロー（`HOW TO FIND US`, `AUTHENTIC JAPAN` 等）を全廃し、見出し自体が内容を語る文（「Three Craft Producers Behind Our Table」「1 Minute from Hotarugaike Station East Exit」等）に書き換えた。

### 5. デザイントークン定義 (`app/globals.css`)

- **余白の階段**: `4px (0.25rem)`, `8px (0.5rem)`, `12px (0.75rem)`, `16px (1rem)`, `24px (1.5rem)`, `32px (2rem)`, `48px (3rem)`, `64px (4rem)`, `96px (6rem)`。見出しの上は下より常に広く取る。
- **角丸**: 役割ごとに固定。構造枠・写真枠・品書き枠は `0px` または `2px` (`--radius-ledger: 2px`)、ボタン・入力欄は `2px` (`--radius-control: 2px`)、食習慣・アレルゲンピルは `9999px` (`--radius-pill: 9999px`)。全部同じ `rounded-md` にはしない。
- **影**: 通常の面は影ではなく `1px solid var(--color-border)` で区切る。モーダルやドロワーなど本当に浮く層だけに、ずらしとぼかしを持つ `--shadow-floating: 0 16px 36px -8px oklch(0.20 0.012 60 / 0.22)` を使う。
- **動き**: 無限ループで揺れる文字や回転するアイコンは全廃。時間帯タブや食習慣フィルタを切り替えたときの品書きの整然とした切り替わりと、ページ初期表示の1回だけの穏やかなフェード (`cubic-bezier(0.22, 1, 0.36, 1)`) に絞る。`transition: all` は禁止し、`transition-colors`, `transition-transform`, `transition-opacity` を明示する。

## フェーズ3 コンポーネント設計

### 1. 素の要素（Primitives）
1. **見出し (`Heading`)**: `font-serif` (`Shippori Mincho`)、`text-balance`、`tracking-tight`〜`tracking-normal`。アイブローなし、1語色変えなし。
2. **本文 (`Prose`)**: 1行あたり欧文 65〜72ch、行間 `1.75`。
3. **ボタン・行動リンク (`ActionLink` / `ActionButton`)**:
   - `variant="primary"`: 朱漆背景 (`bg-urushi text-shikkui hover:bg-urushi-deep`)、高さ最低 `44px`、`px-6 py-3`、押した後の結果を書くラベル（例: `Browse Full Menu by Time Slot`、`Open Route in Google Maps`）。
   - `variant="secondary"`: 白漆喰または透明地に黒鉄枠 (`border border-border-strong text-foreground hover:bg-surface-muted`)、高さ最低 `44px`。
   - ネスト禁止：`href` がある場合は `<Link>` 自体にボタンスタイルを当て、`<Link><button>` は絶対に使わない。
4. **バッジ (`DietaryBadge` / `AllergenBadge`)**:
   - 食習慣 (`Vegan`, `Vegetarian`, `Pork-free`): 麹葉色 (`bg-koji/12 text-koji border border-koji/30`) + アイコンなしでも判別できる明快なラベル。
   - アレルゲン (`Contains: wheat, soy...`): 控えめな枠線と明瞭なテキスト (`text-text-secondary border-border`)。
5. **画像枠 (`DishMediaFrame`)**:
   - 実画像が存在する品目（44品）: `aspect-[4/3]` で `next/image` を表示し、クリックで拡大ダイアログを開く。
   - 実画像が未収録の品目（29品）: `next/image` を呼ばず（400エラー防止）、比率 `aspect-[4/3]` を固定した和紙色の図版枠にカテゴリ別の線画SVG（丼・徳利・ビアグラス・小鉢・甘味）と `Photo in preparation` ラベルを静かに表示する。

### 2. 複合部品（Compound / Domain Components）
1. **ヘッダー (`Header`) & モバイルドロワー (`Sidebar`)**:
   - 最上部に「蛍池駅東口 徒歩1分・本日の営業時間」のコンパクトな案内帯を備え、スクロール時も `/menu` のスティッキーバーと衝突しないよう高さを固定 (`--header-height: 4rem` / `md:4.5rem`)。
   - モバイルドロワーは `role="dialog"`, `aria-modal="true"`, `Escape` キー閉じ、背景スクロールロック、`overscroll-behavior: contain` を備える。
2. **ライブ時間帯スイッチャー (`TimeSlotBar`)**:
   - `Lunch (11:30–14:30)`, `Sunset (14:30–17:30)`, `Dinner (17:30–22:00)`, `Midnight (Wed–Sat 22:00–23:30)` の4区分を切り替え、現在時刻の区分には `Current slot` インジケーターを表示する。
3. **お品書き帳カード (`MenuLedgerItem`)**:
   - 横スクロール専用カルーセルをやめ、全画面で見渡せる2〜3列の「仕込み帳グリッド」にする。
   - サイズ別価格（`normal ¥1,080` / `+egg ¥1,240` / `special ¥1,680` 等）を `tabular-nums` の整然としたドットリーダー付き価格表として表示する。
4. **店頭・タクシー提示カード (`ShowToStaffCard`)**:
   - `/access`（タクシー・駅員への住所提示）と `/events`（スタッフへのステッカー・味噌特典提示）に、日本語と英語を併記した1px二重罫線の「提示用札（Show this screen）」を用意する。
