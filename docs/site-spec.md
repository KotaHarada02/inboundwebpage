# 要件定義書 (`docs/site-spec.md`)

## 1. 目的

- **誰のサイトか**: 大阪府豊中市・蛍池駅東口徒歩1分（大阪伊丹空港からモノレールで1駅3分）にある「発酵と味噌と麺 みつか坊主（Mitsukabose）」の海外旅行者・インバウンド客向け公式案内サイト。
- **誰が見るか**:
  1. 大阪伊丹空港（ITM）に到着・出発する前後、または阪急宝塚線・大阪モノレール沿線で食事場所を探している海外旅行者・英語話者。
  2. ヴィーガン・ベジタリアン・豚肉不使用など、日本のラーメン店で食事制限の壁にぶつかりがちな旅行者やその同行者。
  3. 大阪・北摂のクラフトビール（箕面ビール・オリゼーブルーイング）や自然酒（能勢・秋鹿酒造）と発酵料理のペアリングを楽しみたい食通・ローカル客。
- **訪問者に何をしてもらうか（1つに絞る）**: **「いま提供中の時間帯（Lunch / Sunset / Dinner / Midnight）のお品書きと営業状態・駅からの1分ルートを確認し、迷わず来店して注文を決めること」**。
- **成功とは何か**:
  - トップページを開いて3秒以内に「何の店で、どこにあり、今日いま何時まで開いていて、何が食べられるか」が分かること。
  - 来店前に食事制限（Vegan / Vegetarian / Allergens）や価格・サイズを確認でき、店舗入口（エアポートセンタービル2Fの階段）で迷わないこと。

## 2. 代表的な訪問者（ペルソナ 3名）

1. **空港トランジット・到着直後の旅行者（スマホ・片手操作・移動中）**
   - 場面: 伊丹空港に着陸後、モノレールで1駅の蛍池駅周辺で「本物の日本のラーメンとクラフトビール」を検索してサイトを開く。
   - 知りたいこと: 駅から何分歩くか、予約が必要か（予約不要・ウォークイン）、今日営業しているか、大きな荷物でも2Fの入口がどこか。
2. **ヴィーガン／食制限のあるグループ旅行者（スマホ／タブレット・比較検討中）**
   - 場面: 肉を食べる友人とヴィーガンの自分が一緒に楽しめるラーメン店を探している。
   - 知りたいこと: ヴィーガン担々麺やベジ味噌ラーメンが現在の時間帯（Lunch / Dinner）に注文できるか、アレルゲン（大豆・小麦・落花生など）が明記されているか。
3. **発酵文化・クラフトビール・日本酒の愛好家（PC／スマホ・滞在計画中）**
   - 場面: 単なるラーメン屋ではなく、大阪・北摂のローカルな醸造文化（秋鹿酒造、箕面ビール、オリゼーの米麹ビール、豊能町の味噌）を体験できる場所を探している。
   - 知りたいこと: なぜこの店が蛍池にあるのか、どんな醸造所のお酒と料理があるのか、夕方（Sunset 14:30〜17:30）や深夜（Midnight 水〜土 22:00〜23:30）の楽しみ方。

## 3. ページ構成と伝える優先順位

ページごとの種類（impeccable 分類）と優先順位:

1. **`/`（トップページ — 説得する Persuade）**
   - 優先1: 屋号・店の正体（発酵・白味噌ラーメン＆大阪クラフトビール・自然酒）と、**本日の営業ステータス・4つの時間帯（Lunch / Sunset / Dinner / Midnight）・蛍池駅東口徒歩1分（伊丹空港からモノレール3分）の即断パネル**。
   - 優先2: 看板の一杯（白味噌ラーメン・赤味噌・ヴィーガン担々麺など）と大阪・北摂の醸造ペアリング（秋鹿・箕面ビール・オリゼー）への直結導線。
   - 優先3: みつか坊主の3つの骨格（①人を醸す「発酵と味噌と麺のテーマパーク」、②2022年梅田から創業の地・蛍池への集約と再発酵、③北摂・里山の発酵生態系）を、実店舗の写真とともに編集記事として伝える。
   - 優先4: 2F入口の写真つきアクセス・営業時間・Googleマップ。
2. **`/menu`（お品書き — 操作する Operate + 説得する Persuade）**
   - 優先1: 時間帯切替（Lunch 11:30–14:30 / Sunset 14:30–17:30 / Dinner 17:30–22:00 / Midnight 水〜土 22:00–23:30）と、**食習慣フィルタ（All / Vegan & Vegetarian / No Pork / Spicy）**。
   - 優先2: カテゴリジャンプ（Ramen, Kaedama, Side Dishes, Craft Beer, Japanese Sake, Wine, Soft Drinks, Dessert, Specials）。
   - 優先3: 各品目の名前、価格（サイズ別一覧・`tabular-nums`）、食習慣・アレルゲンバッジ、説明文、実写真（未撮影品はカテゴリ別の誠実な図版枠）。
3. **`/food-and-drinks`（醸造と料理の物語 — 読む Read + 説得する Persuade）**
   - 優先1: 3つの醸造パートナー（箕面ビール、オリゼーブルーイング、秋鹿酒造）とみつか坊主の味噌ラーメンの背景ストーリー。
   - 優先2: 各生産者の代表的な銘柄・料理の一覧と `/menu` への導線。
4. **`/events`（来店＆レビュー特典 — 説得する Persuade）**
   - 優先1: WEBサイト訪問特典（スタッフに伝えてオリジナルステッカー進呈）と Google マップレビュー特典（特製味噌サンプル進呈）の2つの具体的な受け取り手順。
   - 優先2: スタッフに見せやすい店頭提示カード表示と利用条件。
5. **`/access`（アクセス・2F入口案内 — 操作する Operate）**
   - 優先1: 蛍池駅東口から徒歩1分・伊丹空港からモノレール1駅（3分）の経路と、エアポートセンタービル2F階段入口の写真ガイド。
   - 優先2: 営業時間・定休日（月・火）・電話番号・住所（英語／日本語併記でタクシーや駅員に見せられる表示）・Googleマップ。
6. **`/styleguide`（デザインシステム確認用ページ — 内部検証用）**
   - トークン（色・書体・余白・角丸・影）と素の要素・複合部品・各状態（通常・ホバー・フォーカス・無効・空・画像欠落枠）を一覧できる検証ページ。

## 4. 機能：要るもの・要らないもの

- **要るもの**:
  - 現在の曜日・時刻（JST）に応じた営業ステータス表示とデフォルト時間帯タブの自動選択。
  - `/menu` のサーバーサイド初期描画（SSR）＋ `/api/menu`（DB優先・JSONフォールバック）とのハイドレーション連携。
  - `/menu` の食習慣フィルタ（Vegan / Vegetarian 等）とカテゴリジャンプ。
  - 画像欠落品目（29品）に対する HTTP 400 エラーを出さない事前判定と、品目カテゴリに応じた誠実なプレースホルダー枠。
  - 外国人旅行者が駅員・タクシー運転手・店員にそのまま画面を見せられる「日本語併記カード（住所・入口案内・ステッカー特典提示）」。
- **要らないもの**:
  - オンライン予約フォームや決済カート（店舗が予約不可 `acceptsReservations: false` のウォークイン営業のため、虚偽の予約フォームは作らない）。
  - 実店舗に存在しない和風クリップアート（青海波パターン、浮遊する巨大漢字「醸」「味」、回転し続けるアイコン）。

## 5. 技術構成と実行コマンド

- **フレームワーク**: Next.js 15.3.8 (App Router) + React 19 + TypeScript 5
- **スタイリング**: Tailwind CSS v4 (`@import "tailwindcss"` + `@theme`) + CSS カスタムプロパティ（OKLCH 3層トークン）
- **データ管理**: Neon Serverless Postgres (`@neondatabase/serverless`) + ローカル JSON フォールバック (`infrastructure/data/menu/*.json`)
- **コマンド**:
  - 開発サーバー起動: `npm run dev -- -p 3000`
  - 本番ビルド: `npm run build`
  - 型検査: `npx tsc --noEmit`
  - Lint: `npm run lint`
  - ロジック単体テスト: `node --test scripts/test-menu-utils.mjs`

## 7. 受け入れ条件（フェーズ6で1つずつ検証可能な文）

1. `npm run lint`、`npx tsc --noEmit`、`npm run build`、`node --test scripts/test-menu-utils.mjs` がすべて終了コード `0` で通過すること。
2. 店舗の住所（`〒560-0032 大阪府豊中市蛍池東町1-6-5 エアポートセンタービル2F`）と営業時間（水〜土 11:30–24:00 LO 23:30、日 11:30–22:00 LO 21:30、月火定休）が、`lib/siteConfig.ts`・`infrastructure/data/restaurant.json`・`Footer`・`AccessSection`・`/access`・`RestaurantJsonLd` のすべてで完全に一致していること。
3. 存在しない画像パス（`/images/food-and-drinks/japanese-pattern-dark.jpg`、`/images/hero/hero-1.jpg`、`/images/logo.png`、および未撮影のメニュー画像29点）への `<Image>` リクエストや CSS `url()` が発生せず、画像欠落エラーがゼロであること。
4. `<Link>` の中に `<button>` をネストしている箇所が全ページで `0` 件であること。
5. 全ページのすべての見出しにおいて、AI 特有の「全大文字アイブロー（Kicker）」「見出し内の1語だけの色変え・斜体強調」「意味のない連番（01/02/03）」が撤廃されていること。
6. `/menu` が初回 SSR 時点でメニュー一覧を出力し、JavaScript 実行前でも品名・価格・説明がHTMLに含まれていること。また時間帯切替と食習慣フィルタ（Vegan / Vegetarian / Pork-free 等）が正しく動作すること。
7. `/styleguide` ページで、定義したカラートークン・タイポグラフィ・ボタン・バッジ・カード・画像未収録枠が一目で確認できること。

## 8. やらないこと・触ってはいけないもの

- `/admin` および `/api/admin/*`、`/api/menu` の DB 接続・JWT 認証ロジック・エンドポイント仕様は壊さない（既存の管理フローを維持する）。
- URL パス構造（`/`, `/menu`, `/food-and-drinks`, `/events`, `/access`, `/ramen` → `/menu` リダイレクト）と Google Analytics / Vercel Analytics タグは維持する。
- メニューの品名・価格・説明文・アレルゲン・ストーリーの事実内容は改変しない（表記ゆれの統一のみ行う）。

## 9. 仮定（確認できずに置いて進める前提）

1. **営業時間と郵便番号の正**: 直近の改修 (`siteConfig.ts`, `RestaurantJsonLd.tsx`, `AccessClient.tsx`, `Footer.tsx`) で使われている「〒560-0032」「水〜土 11:30–24:00 (LO 23:30) / 日 11:30–22:00 (LO 21:30) / 月・火定休」を現在の最新営業情報とみなし、古い値が残っていた `infrastructure/data/restaurant.json` 側をこれに揃える。
2. **未撮影メニュー画像29点の扱い**: `public/images/menu/` に実ファイルが存在しない29品目は、AI生成画像で偽装せず（「料理や店内など実在を示す画像はAI生成で代用しない」原則）、品目カテゴリと器・グラスの線画を添えた「Photo in preparation / 撮影準備中」の誠実な図版枠を表示し、`docs/image-brief.md` の「A. 人が撮る・集めるもの」に撮影リストとして記載する。
3. **主言語**: インバウンド向けサイトであるため英語を主言語としつつ、屋号・品目の日本語名・駅名・タクシーや店員に提示する案内ブロックには日本語を併記する。
